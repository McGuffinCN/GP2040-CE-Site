# 获取帮助 / 支持

## Discord

如果您需要帮助，获取快速支持的最佳去处可能是我们的 [Discord 服务器](https://discord.gg/k2pxhke7q8)。

请注意，对于从大多数商家处购买的商业产品，我们不提供支持。在这种情况下，请先联系商家寻求帮助和支持。

请首先阅读 [置顶帖子](https://discord.com/channels/1049366310389289001/1132450634243772519)，然后在 [支持频道](https://discord.com/channels/1049366310389289001/1132447732662018089) 创建帖子，并提供以下信息：

1 - 您是商家吗？
2 - 您使用的是什么设备？
3 - 您在哪里买的？（请附上销售页面链接）
4 - 您是否已就此问题联系过商家？（请简要概述沟通内容）
5 - 您当前运行的固件版本和分发版本是什么？（可通过网页配置器查看）
6 - 您遇到了什么问题？
7 - 您已经进行了哪些故障排除步骤？

请同时附上相关设备正面和背面的照片；如果设备是完整的摇杆或带有外壳，还请至少附上一张控制器主板的照片。如有需要，也请附上网页配置器页面的截图。

任何未填写上述信息或未附图片的支持帖子将不会得到回复。

## Github 问题

您可以在 [Github 上打开一个 issue](https://github.com/OpenStickCommunity/GP2040-CE/issues/new/choose)。
