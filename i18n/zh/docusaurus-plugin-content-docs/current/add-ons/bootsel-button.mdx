# BOOTSEL 键配置

用途：此插件旨在允许将 BOOTSEL 键作为额外的按键输入使用。

![GP2040-CE 配置器 - 插件 BOOTSEL 键配置](../assets/images/gpc-add-ons-bootsel-button.png)

## 网页配置器选项

- `BOOTSEL 键` - 选择一个输入映射到 BOOTSEL 键。

## 硬件

### 要求

此插件仅适用于具有 BOOTSEL 键的设备。

### 安装

此插件没有安装说明。

## 其他注意事项

如果设置了此键，OLED 可能会变得无响应。您可以取消设置以恢复 OLED 功能。

:::warning

`BOOTSEL 键配置` 仅适合有经验的用户使用。

:::
