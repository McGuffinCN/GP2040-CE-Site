# 固件开发

GP2040-CE 是用 C++ 编写的，并设置为标准的 Pico SDK 项目。

参见 [Raspberry Pi Pico 入门指南](https://rptl.io/pico-get-started)。

## 环境设置

大部分内容将重复上面链接的 Raspberry Pi Foundation PDF。

<Tabs groupId="operating-systems" defaultValue="Windows (Pico SDK)">
<TabItem value="Windows (Pico SDK)" label="Windows (Pico SDK)" default>

1. 下载并安装 [CMake](https://github.com/Kitware/CMake/releases/download/v3.27.4/cmake-3.27.4-windows-x86_64.msi)。
2. 安装 [NodeJS](https://nodejs.org/en/download)
3. 安装 [NPM](https://docs.npmjs.com/downloading-and-installing-node-js-and-npm)
4. 下载并安装 [pico-setup-windows-x64-standalone](https://github.com/raspberrypi/pico-setup-windows/releases/)。
5. 下载并安装 VSCode。
6. 下载并安装 [Windows Terminal](https://github.com/microsoft/terminal/releases/tag/v1.17.11461.0)。
7. 打开 Windows Terminal。
8. 通过在 Windows Terminal 中运行以下命令下载 GP2040-CE-main 仓库。这会将文件夹下载到 `C:\Users\user\GP2040-CE`。

   ```console
   git clone https://github.com/OpenStickCommunity/GP2040-CE.git
   cd GP2040-CE
   git submodule update --init
   ```

安装 Raspberry Pi Pico SDK 后，您现在应该有一个“Pico-Visual Studio Code”的快捷方式（使用 Windows 搜索查找）。

8. 通过 Windows 搜索打开“Pico-Visual Studio Code”。这是一个预配置环境变量的快捷方式（稍后会解释）。
9. 通过按 `Ctrl+Shift+X` 导航到扩展窗口。
10. 安装 Microsoft 的“CMake Tools”。
11. 通过“文件 > 打开文件夹”打开您之前下载的 GP2040-CE 文件夹。

1. 安装最新的 [Arm GNU Toolchain](https://developer.arm.com/downloads/-/arm-gnu-toolchain-downloads)
2. 安装最新版本的 [CMake](https://cmake.org/download/)
3. 安装 [Visual Studio Build tools](https://visualstudio.microsoft.com/downloads/#build-tools-for-visual-studio-2022)，或完整的 [Visual Studio Community Edition IDE](https://visualstudio.microsoft.com/downloads/#visual-studio-community-2022)
   - 确保选择带有 C++ 工作负载的桌面开发
   - 从单个组件中选择最新的 Windows 10 或 Windows 11 SDK
4. 安装 [Python 3.10](https://www.python.org/downloads/windows/)
   - 安装结束时，有一个选项可以禁用最大文件路径长度。您需要选择此选项。
5. 安装 [Visual Studio Code](https://code.visualstudio.com/) - 可选
6. 安装 git
   - 将默认编辑器设置为 VIM 以外的任何东西，例如 Visual Studio Code
7. 安装 [NodeJS](https://nodejs.org/en/download) 和 NPM
8. 将 Pico SDK 克隆到本地计算机

   ```console
   git clone https://github.com/raspberrypi/pico-sdk.git
   cd pico-sdk
   git submodule update --init
   cd ..
   ```

9. 从命令提示符中，将 GP2040-CE 克隆到本地计算机

   ```console
   git clone https://github.com/OpenStickCommunity/GP2040-CE.git
   cd GP2040-CE
   ```

#### Ubuntu

此设置假定您了解 Linux 终端的使用。

1. 获取 SDK

   ```bash
   cd ~/
   mkdir pico
   cd pico
   git clone https://github.com/raspberrypi/pico-sdk.git --branch master
   cd pico-sdk
   git submodule update --init
   cd ..
   ```

2. 安装工具链

   ```bash
   sudo apt update
   sudo apt install cmake gcc-arm-none-eabi libnewlib-arm-none-eabi build-essential
   ```

   - 可能还需要安装 `libstdc++-arm-none-eabi-newlib`

3. 安装 NodeJS 和 NPM

   ```bash
   curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash - &&\
   sudo apt-get install -y nodejs
   ```

4. 获取 GP2040-CE

   ```bash
   git clone https://github.com/OpenStickCommunity/GP2040-CE.git
   cd GP2040-CE
   git submodule update --init
   ```

#### Raspberry Pi

此设置脚本需要大约 2.5GB 的 SD 卡磁盘空间。

1. 下载设置脚本

   ```bash
   wget https://raw.githubusercontent.com/raspberrypi/pico-setup/master/pico_setup.sh
   ```

2. 使脚本可执行并运行。

   ```bash
   chmod +x pico_setup.sh
   ```

3. 安装 NodeJS 和 NPM

   ```bash
   curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash - &&\
   sudo apt-get install -y nodejs
   ```

4. 重启您的 Pi

   ```bash
   sudo reboot
   ```

5. 获取 GP2040-CE

   ```bash
   git clone https://github.com/OpenStickCommunity/GP2040-CE.git
   cd GP2040-CE
   git submodule update --init
   ```

## 构建

### 环境变量

已设置多个新环境变量以控制构建流程的各个部分。

| 名称               | 默认值 | 描述                                                                                             |
| ------------------ | ------- | ------------------------------------------------------------------------------------------------------- |
| GP2040_BOARDCONFIG | Pico    | 用于构建的 boards.h 配置文件。                                                          |
| SKIP_WEBBUILD      | FALSE   | 确定在 cmake 配置步骤中是否构建 Web 配置器。                   |
| SKIP_SUBMODULES    | FALSE   | 确定在 cmake 配置步骤中是否自动运行子模块初始化命令。 |

#### SDK 变量

我们利用了一些 SDK 变量进行构建。

| 名称       | 默认值 | 描述                                                                                                                                                                    |
| ---------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| PICO_BOARD | pico    | 这是 RP2040 芯片所属的嵌入式板。默认情况下，它假定为 Pico。此变量应与板配置文件夹中的 `<boardname.h>` 文件匹配。 |

<TabItem value="Windows (Pico SDK)" label="Windows (Pico SDK)" default>

安装 Raspberry Pi Pico SDK 后，您现在应该有一个“Pico-Visual Studio Code”的快捷方式（使用 Windows 搜索查找）。此快捷方式应已配置好所有内容，**允许您跳到第 7 步**。如果您遇到编译问题，请考虑遵循此处概述的手动步骤。

确保 `PICO_SDK_PATH` 环境变量已设置：

1. 在 Windows 中搜索“编辑帐户的环境变量”。
2. 在“用户变量”下，点击“新建...”。
3. 在出现的对话框中，输入 `PICO_SDK_PATH` 作为变量名称。
4. 点击“浏览目录”并导航到 `C:\Program Files\Raspberry Pi\Pico SDK v1.5.1\pico-sdk` 作为变量值。
5. 创建另一个新变量。
6. 输入 `GP2040_BOARDCONFIG` 作为变量名称。
7. 输入 `Pico`（或您编辑的配置文件夹的名称）作为变量值。

您也可以在 VSCode 中设置变量：

1. 按 `Ctrl + ,` 打开设置。
2. 使用搜索栏查找“CMake”。
3. 向下滚动直到看到“CMake: Configure Environment”。
4. 点击“添加项目”。
5. 键：`GP2040_BOARDCONFIG`
6. 值：`Pico`（或您的工作文件夹名称）。

当提示时，为 GP2040-CE 选择 `GCC 10.3.1 ARM NONE EABI`。

在 VSCode 内：

1. 点击 VSCode 左侧边栏的 CMake 图标。
2. 您将在 CMake 项目概述的右上角看到三个图标。点击“配置所有项目”图标（看起来像一个带箭头的页面）。
3. 等待配置过程完成。如果进度不可见，请通过单击“终端”菜单，然后“新终端”在 VSCode 中打开一个新终端。新终端窗口将在底部打开，导航到“输出”选项卡。
4. 在 CMake 项目概述中点击“构建所有项目”。
5. 文件应位于 GP2040-CE 文件夹内的新文件夹“build”中。

</TabItem>
<TabItem value="Windows (Manual)" label="Windows (Manual)" default>

从 GP2040-CE 文件夹开始。**从开发者 PowerShell 或开发者命令提示符**：

:::note

设置环境变量后需要新的 PowerShell 或命令提示符会话。

:::

1. 确保已将 `PICO_SDK_PATH` 环境变量设置为 pico-sdk 文件夹的路径。
2. （可选）将 `GP2040_BOARDCONFIG` 环境变量设置为板配置的文件夹名称。

   - 默认值为 `Pico`

3. 创建构建目录，配置构建并执行构建。

   ```console
   mkdir build
   cd build
   cmake -G "NMake Makefiles" ..
   nmake
   ```

4. 您的 UF2 文件应位于构建目录中。

</TabItem>

<TabItem value="macOS" label="macOS" default>

从 GP2040-CE 文件夹开始

1. 确保已将 `PICO_SDK_PATH` 环境变量设置为 pico-sdk 文件夹的路径：

   ```bash
   export PICO_SDK_PATH=~/pico/pico-sdk
   ```

2. （可选）将 `GP2040_BOARDCONFIG` 环境变量设置为板配置的文件夹名称：

   ```bash
   export GP2040_BOARDCONFIG=Pico
   ```

   - 默认值为 `Pico`

3. 创建构建目录，配置构建并执行构建：

   ```bash
   mkdir build
   cd build
   cmake ..
   make
   ```

4. 您的 UF2 文件应位于构建目录中。
