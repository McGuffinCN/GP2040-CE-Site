# 配置

:::note

我们正在尝试从编译时配置转向运行时配置。

:::

构建 GP2040-CE 固件有两种简单选项：可以编辑现有的板定义，或创建自己的定义。多个示例配置位于仓库的 **[configs](https://github.com/OpenStickCommunity/GP2040-CE/tree/main/configs)** 文件夹中。本文件将概述如何设置新的构建配置。

## 板配置文件夹

[`configs`](https://github.com/OpenStickCommunity/GP2040-CE/tree/main/configs) 中的每个子文件夹包含一个单独的板配置，包括以下内容：

| 名称            | 必须？    | 描述                                                                                                                                                                                                                 |
| --------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `BoardConfig.h` | 是        | 用于为特定控制器/板构建 GP2040-CE 的配置文件。包含初始 GPIO 引脚映射、LED 配置等。                                                                                 |
| `README.mdx`    | 否        | 提供与此板配置相关的信息。不是构建过程所需，但建议在提交新板配置的 pull request 时包含。                                                                  |
| `assets/`       | 否        | 包含在 `README.mdx` 中的资源文件夹。不是构建过程所需。                                                                                                                              |
| `<boardname.h>` | 否        | 板定义文件，以板本身命名，用于通过 Pico SDK 配置板特定的 SDK 功能。[Pico 示例](https://github.com/raspberrypi/pico-sdk/blob/master/src/boards/include/boards/pico.h) |

## 板配置 (`BoardConfig.h`)

`BoardConfig.h` 文件中可用的板选项如下：

| 名称                                     | 描述                                                                                                                                                                             | 必须？    |
| ---------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------- |
| **PIN*DPAD*_X_**<br />**PIN*BUTTON*_X_** | 按钮的 GPIO 引脚。用 GP2040-CE 按钮或 DPad 方向替换 _`X`_。                                                                                                 | 是        |
| **DEFAULT_SOCD_MODE**                    | 使用的默认 SOCD 模式，默认为 `SOCD_MODE_NEUTRAL`。<br />可用选项包括：<br />`SOCD_MODE_NEUTRAL`<br />`SOCD_MODE_UP_PRIORITY`<br />`SOCD_MODE_SECOND_INPUT_PRIORITY` | 否        |
| **BUTTON_LAYOUT**                        | 用于每个按钮 LED 和外部显示器的控件/按钮布局。<br />可用选项包括：<br />`BUTTON_LAYOUT_STICKLESS`<br />`BUTTON_LAYOUT_WASD`                 | 是        |

创建 `configs/NewBoard/BoardConfig.h` 并添加您的引脚配置和选项。示例 `BoardConfig.h` 文件：

```cpp
// BoardConfig.h

#include <GamepadEnums.h>

#define PIN_DPAD_UP     2
#define PIN_DPAD_DOWN   3
#define PIN_DPAD_LEFT   4
#define PIN_DPAD_RIGHT  5
#define PIN_BUTTON_B1   6
#define PIN_BUTTON_B2   7
#define PIN_BUTTON_B3   8
#define PIN_BUTTON_B4   9
#define PIN_BUTTON_L1   10
#define PIN_BUTTON_R1   11
#define PIN_BUTTON_L2   26
#define PIN_BUTTON_R2   27
#define PIN_BUTTON_S1   16
#define PIN_BUTTON_S2   17
#define PIN_BUTTON_L3   18
#define PIN_BUTTON_R3   19
#define PIN_BUTTON_A1   20
#define PIN_BUTTON_A2   21
#define PIN_BUTTON_TURBO -1
#define PIN_SLIDER_LS    -1
#define PIN_SLIDER_RS    -1

#define DEFAULT_SOCD_MODE SOCD_MODE_NEUTRAL
#define BUTTON_LAYOUT BUTTON_LAYOUT_ARCADE
```

### RGB LEDs

GP2040-CE 支持每个按钮的 WS2812 及类似 RGB LED。

`BoardConfig.h` 文件中可用的 RGB LED 选项如下：

| 名称                                       | 描述                                                                                                                                                             | 必须？                          |
| ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------- |
| **BUTTON_LAYOUT**                          | 用于每个按钮 LED 和外部显示器的控件/按钮布局。<br />可用选项包括：<br />`BUTTON_LAYOUT_STICKLESS`<br />`BUTTON_LAYOUT_WASD` | 是                                |
| **BOARD_LEDS_PIN**                         | 您的 LED 串的数据引脚                                                                                                                                            | 是                                |
| **LED_FORMAT**                             | LED 链的颜色数据格式。<br />可用选项包括：<br />`LED_FORMAT_GRB`<br />`LED_FORMAT_RGB`<br />`LED_FORMAT_GRBW`<br />`LED_FORMAT_RGBW`          | 否，默认值为 `LED_FORMAT_GRB` |
| **LEDS_PER_PIXEL**                         | 每个按钮的 LED 数量。                                                                                                                                          | 是                                |
| **LED_BRIGHTNESS_MAXIMUM**                 | 最大亮度值，`uint8_t` 0-255。                                                                                                                                  | 是                                |
| **LED_BRIGHTNESS_STEPS**                   | 使用上下热键时的亮度级数。                                                                                                           | 是                                |
| **LEDS*DPAD*_X_**<br />**LEDS*BUTTON*_X_** | LED 链上按钮的索引。用 GP2040-CE 按钮或 DPad 方向替换 _`X`_。                                                                    | 是                                |
| **LEDS_BASE_ANIMATION_INDEX**              | 默认 LED 动画索引。                                                                                                                                        | 否，默认为 `1`                |
| **LEDS_STATIC_COLOR_INDEX**                | 静态颜色主题的默认颜色索引                                                                                                                      | 否，默认为 `2`                |
| **LEDS_BUTTON_COLOR_INDEX**                | 按钮按下颜色的默认颜色索引                                                                                                                    | 否，默认为 `1`                |
| **LEDS_THEME_INDEX**                       | 静态主题的默认主题索引                                                                                                                               | 否，默认为 `0`                |
| **LEDS_RAINBOW_CYCLE_TIME**                | 彩虹循环主题的颜色循环时间                                                                                                                            | 否，默认为 `40`               |
| **LEDS_CHASE_CYCLE_TIME**                  | 彩虹追逐主题的动画速度                                                                                                                         | 否，默认为 `85`               |

`BoardConfig.h` 文件中的 RGB LED 设置示例：

```cpp
// BoardConfig.h

#include "gp2040.h"
#include "NeoPico.hpp"

#define BUTTON_LAYOUT BUTTON_LAYOUT_STICKLESS

#define BOARD_LEDS_PIN 22

#define LED_BRIGHTNESS_MAXIMUM 100
#define LED_BRIGHTNESS_STEPS 5
#define LED_FORMAT LED_FORMAT_GRB
#define LEDS_PER_PIXEL 2

#define LEDS_DPAD_LEFT   0
#define LEDS_DPAD_DOWN   1
#define LEDS_DPAD_RIGHT  2
#define LEDS_DPAD_UP     3
#define LEDS_BUTTON_B3   4
#define LEDS_BUTTON_B4   5
#define LEDS_BUTTON_R1   6
#define LEDS_BUTTON_L1   7
#define LEDS_BUTTON_B1   8
#define LEDS_BUTTON_B2   9
#define LEDS_BUTTON_R2   10
#define LEDS_BUTTON_L2   11
```

### 玩家 LED

GP2040-CE 支持 PWM 和 RGB 玩家 LED (PLEDs)，可以在 `BoardConfig.h` 文件中配置。

:::note

RGB PLEDs 需要配置 [RGB LEDs](#rgb-leds)。

:::

`BoardConfig.h` 文件中可用的 PLED 选项如下：

| 名称          | 描述                                                                                | 必须？    |
| ------------- | ------------------------------------------------------------------------------------------ | --------- |
| **PLED_TYPE** | 配置 PLED 的类型。<br />可用选项包括：`PLED_TYPE_PWM`, `PLED_TYPE_RGB` | 是       |
| **PLED1_PIN** | (PWM) PLED #1 的 GPIO 引脚。<br />(RGB) LED 链上 PLED #1 的索引。          | 是       |
| **PLED2_PIN** | (PWM) PLED #2 的 GPIO 引脚。<br />(RGB) LED 链上 PLED #2 的索引。          | 是       |
| **PLED3_PIN** | (PWM) PLED #3 的 GPIO 引脚。<br />(RGB) LED 链上 PLED #3 的索引。          | 是       |
| **PLED4_PIN** | (PWM) PLED #4 的 GPIO 引脚。<br />(RGB) LED 链上 PLED #4 的索引。          | 是       |

`BoardConfig.h` 文件中的 PLED 设置示例：

```cpp
// BoardConfig.h

#include "PlayerLEDs.h"

#define PLED_TYPE PLED_TYPE_RGB
#define PLED1_PIN 12
#define PLED2_PIN 13
#define PLED3_PIN 14
#define PLED4_PIN 15
```

### I2C 显示器

GP2040-CE 支持运行在 SSD1306、SH1106 或 SH1107 驱动上的 128x64 单色显示器。可用的显示器选项如下：

| 名称                 | 描述                                                                                                                                                                                                                                                  | 必须？                       |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------- |
| **BUTTON_LAYOUT**    | 用于每个按钮 LED 和外部显示器的控件/按钮布局。<br />可用选项包括：<br />`BUTTON_LAYOUT_STICKLESS`<br />`BUTTON_LAYOUT_WASD`                                                                                      | 是                             |
| **HAS_I2C_DISPLAY**  | 标志指示控制器包含 I2C 显示模块。                                                                                                                                                                                              | 否                              |
| **DISPLAY_I2C_ADDR** | 显示器的 I2C 地址。                                                                                                                                                                                                                              | 否，默认为 `0x3C`          |
| **I2C_SDA_PIN**      | I2C SDA 线的 GPIO 引脚。                                                                                                                                                                                                                           | 如果启用 `HAS_I2C_DISPLAY` |
| **I2C_SCL_PIN**      | I2C SCL 线的 GPIO 引脚。                                                                                                                                                                                                                           | 如果启用 `HAS_I2C_DISPLAY` |
| **I2C_BLOCK**        | Pico 上的 I2C 块。参考 [Pico 引脚图](https://datasheets.raspberrypi.com/pico/Pico-R3-A4-Pinout.pdf) 以识别使用的 SDA 和 SCL 引脚的块。<br />可用选项包括：<br />`i2c0`<br />`i2c1` | 否，默认为 `i2c0`          |
| **I2C_SPEED**        | I2C 总线的速度。`100000` 是标准模式，而 `400000` 用于快速模式通信。可以使用更高的值，但需要测试设备是否支持。                                                                          | 否，默认为 `400000`        |
| **DISPLAY_FLIP**     | 标志翻转渲染的显示输出。设置为 `1` 以启用。                                                                                                                                                                                              | 否，默认为 `0`             |
| **DISPLAY_INVERT**   | 标志反转渲染的显示输出。设置为 `1` 以启用。                                                                                                                                                                                            | 否，默认为 `0`             |

`BoardConfig.h` 文件中的 I2C 显示器设置示例：

```cpp
#define BUTTON_LAYOUT BUTTON_LAYOUT_WASD
#define HAS_I2C_DISPLAY 1
#define I2C_SDA_PIN 0
#define I2C_SCL_PIN 1
#define I2C_BLOCK i2c0
#define I2C_SPEED 800000
```

#### I2C 显示器自定义按钮布局

从 v0.7.9 开始，您可以通过 boardconfig.h 创建自定义 `left` 和 `right` 显示布局，作为 `DEFAULT_BOARD_LAYOUT_A` 和 `DEFAULT_BOARD_LAYOUT_B`。

您可以在 [Zero Rhythm BoardConfig.h](https://github.com/OpenStickCommunity/GP2040-CE/blob/main/configs/ZeroRhythm/BoardConfig.h#L90) 文件中找到设置示例。

有关可能性的完整细分，请参见下文。

```cpp
BUTTON_GROUP 结构
{
  {element, {x, y, w, h, stroke, fill, value, object, ...extra}},
  ...
}

element - 以下类型之一
GP_ELEMENT_WIDGET      - 通用小部件（需要扩展）
GP_ELEMENT_SCREEN      - 屏幕（仅定义为根级显示导航元素）
GP_ELEMENT_BTN_BUTTON  - 按钮（游戏手柄按钮掩码）
GP_ELEMENT_DIR_BUTTON  - 按钮（游戏手柄 D-Pad 掩码）
GP_ELEMENT_PIN_BUTTON  - 按钮（GPIO 数字引脚）
GP_ELEMENT_LEVER       - 杆（使用 D-Pad 模式确定动作 - dpad 或模拟）
GP_ELEMENT_LABEL       - 文本标签（需要一些改进）
GP_ELEMENT_SPRITE      - 精灵对象（相同 - 用于在布局上放置静态图像）
GP_ELEMENT_SHAPE       - 形状对象（类似于按钮元素，但无反应）

object - 以下类型之一
GP_SHAPE_ELLIPSE
GP_SHAPE_SQUARE
GP_SHAPE_DIAMOND
GP_SHAPE_POLYGON
GP_SHAPE_ARC

x, y, w, h - 取决于对象类型

GP_SHAPE_ELLIPSE
x, y     椭圆的中心
w        半径

GP_SHAPE_SQUARE
x, y     左/顶部位置
w, h     右/底部位置

GP_SHAPE_DIAMOND
x, y     形状的中心
w        大小

GP_SHAPE_POLYGON
x, y     多边形的中心
w        半径
h        边数
extra[0] 旋转

GP_SHAPE_ARC
x, y     弧的中心（假设椭圆）
w        半径
extra[0] 角度的起点（angle）
extra[1] 角度的终点（angleEnd）
extra[2] 画到角度的内点（closed）
```

#### I2C 显示器启动画面

固件还具有启动画面显示功能。默认启动图像已在 `headers/add-ons/i2cdisplay.h` 中定义。启动图像的数据是表示要在 OLED 屏幕上显示的位图的字节。启动图像可以通过 web-config 设置。如果您想更改启动图像的默认版本（以保留它超出数据擦除），可以在活动的 `BoardConfig.h` 文件中使用名为 `DEFAULT_SPLASH` 的 C 定义进行自定义。
生成这些字节的说明如下：

1. 导航到 [Bitmap Converter web utility](https://marlinfw.org/tools/u8glib/converter.html)
2. 配置生成的代码
   - 选择 Marlin 2.x 和 Bitmap，取消勾选其他选项。
3. 上传启动图像文件
   - 单击“选择文件”后设置图像文件。图像文件需要预处理到您喜欢的样式并裁剪为 128x64。这应该在下面填充一个代码块。
4. 使用生成的代码

   - 从代码块中复制大括号内的十六进制数字。
   - 导航到您选择的 `BoardConfig.h`，在文件末尾 `#endif` 之前创建一个 C 定义，如下所示：

     ```cpp
     #define DEFAULT_SPLASH \
     ```

   - 然后在刚输入的内容下面粘贴您复制的内容。确保按如下方式编辑字节数组：

     ```cpp
     0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00, \ // 第一行
     0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00, \ // 第二行
     ... // 所有行都以 \ 结尾，类似于上面的行
     ```
